# Лендінг: обіцянка → статус (звіряти перед кожним релізом)

| Обіцянка на about.html | Реальний статус | Дія |
|---|---|---|
| Заявки з Prom/Rozetka самі падають у чергу | Polling + вебхуки є; фонові Celery-воркери є | OK |
| Нова Пошта (авто-ТТН) | Адаптер + трекінг є; ключі клієнта потрібні | OK |
| Checkbox / LiqPay / Monobank | Адаптери є (stub без ключів) | OK, без «Скоро» |
| AI пише листи | Шаблони + Claude за ключем; без ключа — локальний шаблон | OK |
| Автоматизації «якщо → то» | Движок є; візуального конструктора в UI нема | Додати «Скоро» біля згадки конструктора |
| Безпека і довіра | Фаза 1 закрита (тести зелені) | OK |
| Демо-режим | Превʼю-мок + `?demo=1` з плашкою | OK |
| Тарифи Pro 350 / Team 300 | Підписано «знижка від 5 місць» | OK |
