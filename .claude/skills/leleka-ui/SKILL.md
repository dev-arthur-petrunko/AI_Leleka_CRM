# UI-правила AI Leleka CRM
1. Каркас: боковая панель на ≥1024px, нижнее меню из 5 пунктов на телефоне; «Угоди» и «Замовлення» всегда в основном меню.
2. Цвета только из токенов (tokens.css); темы «Ранок» (morning) и «Вечір» (evening); hex в компонентах запрещены. Графики читают токены.
3. Компоненты shadcn/ui + lucide-react; эмодзи в интерфейсе запрещены.
4. Каждый экран имеет 4 состояния: загрузка (скелетон), данные, пусто (с кнопкой действия), ошибка (с «Повторити»).
5. Подписи только через словарь i18n (uk); технические коды пользователю не показываются.
6. Статус и приоритет: цвет + иконка + текст.
7. Угода ≠ Замовлення: карточки угод называются «Угода #…».
8. Никаких молчаливых моков; демо только с DEMO_MODE и плашкой «Демо-дані».
9. После правок: Playwright-снимки на 390px и 1280px в обеих темах; check-contrast зелёный.
