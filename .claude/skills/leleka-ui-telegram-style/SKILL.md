# UI-правила
1. Стиль Telegram WebApp: токены --tg-bg, --tg-card, --tg-text, --tg-hint, --tg-link, --tg-btn; радиусы 12/10/20px. Брендовая тема Leleka только на about.html.
2. У каждого экрана 4 состояния: загрузка (скелетон), данные, пусто (с подсказкой действия), ошибка (с кнопкой «Повторить»).
3. Запрещён молчаливый фолбек на моки. Демо-данные только при явном демо-режиме и с видимой плашкой «Демо».
4. Статус не передаётся одним цветом: рядом иконка или текст.
5. Десктоп (от 1024px): боковая панель слева, таблицы с сортировкой и фильтрами; мобильный: нижний таб-бар не более 5 пунктов.
6. После правок: открыть экран через Playwright, снять скриншот на 390px и 1280px.
